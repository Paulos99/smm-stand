# Лаборатория форматов СММ ШКОЛЫ (тестовый стенд)

Стенд, на котором команда пробует новые форматы обучения. У каждого формата два варианта, А и Б. Тестировщик переключает их сам, ставит оценку, пишет комментарий, а статистика сравнивает варианты рядом.

Адрес: https://paulos99.github.io/smm-stand/

Вход без пароля: человек пишет имя и выбирает роль «Ученик» или «Учитель». Роль переключается кнопкой в шапке. Учителю дополнительно видны статистика и ИИ-сборщик игр. Расход ИИ ограничен: 40 запросов в день на имя, 80 на один IP и 400 на весь стенд.

Прод smmorbita.ru стенд не трогает: отдельный репозиторий, отдельный бэкенд, отдельная база.

## Как устроено

```
index.html            шапка, бегущая строка, подвал
css/app.css           токены smmorbita + светлая тема [data-theme=light]
data/formats.json     список форматов и их варианты А/Б (главный конфиг)
js/config.js          адреса API (два адреса для работы с VPN и без)
js/api.js             запросы к API, вход, запасной адрес
js/track.js           аналитика: открытие, шаги, прохождение, время
js/feedback.js        форма отзыва (имя обязательно, оценка, удобство, комментарий)
js/app.js             роутер: #/login, #/, #/f/<id>/<A|B>, #/dash
js/dashboard.js       статистика для команды
js/formats/<type>.js  один модуль на тип формата
```

Учебный контент (уроки, кейсы, тексты лекций) в репозиторий не попадает: его отдаёт API только после входа.

## Как добавить вариант к формату

Варианты задаются в `data/formats.json`:

```json
"variants": {
  "A": { "label": "Сторис", "desc": "Короткие экраны по тапу", "params": { "mode": "stories" } },
  "B": { "label": "Шпаргалка", "desc": "Всё на одном экране", "params": { "mode": "longread" } }
}
```

Модуль формата получает `ctx.params` выбранного варианта и по ним меняет поведение. Чтобы попробовать другой подход, поменяйте `params` у варианта (и при необходимости добавьте их обработку в модуль). Статистика по вариантам начнёт считаться сама.

## Как добавить новый формат

1. Добавьте объект в `data/formats.json`: `id`, `type`, `title`, `group`, `source` (`встреча` или `новая`), `icon` (имя стикера из `assets/stickers`), `short`, `steps` (названия шагов для воронки) и `variants` A/Б. Флаг `teacherOnly: true` прячет формат от учеников.
2. Создайте `js/formats/<type>.js`:

```js
export default function (stage, ctx) {
  // ctx.variant 'A' | 'B', ctx.params, ctx.content, ctx.me, ctx.isTeacher
  // ctx.step('имя-шага')  отметить шаг (для воронки)
  // ctx.click('кнопка')   отметить клик
  // ctx.award(баллы, { complete: true, sticker: ['first'] })  баллы и прохождение
  // ctx.api('/api/...')   запрос к API, ctx.toast('текст')
  stage.replaceChildren(ctx.h('p', {}, 'Привет!'));
  return () => {}; // необязательно: уборка таймеров при уходе
}
```

3. Если формату нужен контент, добавьте его в `content/content.json` на сервере (репозиторий бэкенда приватный) и задеплойте API.

## Тема

По умолчанию берётся тема системы. Кнопка ☀/☾ в шапке переключает и запоминает выбор (`localStorage['stand-theme']`).

## Бэкенд

Yandex Cloud, ru-central1: отдельный Serverless Container `smm-stand` и отдельная YDB `smm-stand-db`. ИИ: YandexGPT Lite через сервисный аккаунт контейнера, с дневными лимитами на человека и на весь стенд.
